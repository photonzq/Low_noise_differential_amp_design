# Scripts of the low-noise preamplifier note

Python 3.13 (Anaconda), NumPy, SciPy (`sr560_bw_check.py`'s fits, `nf5113_manual.py`'s image processing and fits), Matplotlib, schemdraw, PyMuPDF and Pillow (the plot readings); ngspice-46 as the shared library of KiCad 10 (`ngspice_shared.py` finds it). Every script writes its decks to `../sim/runs/` and its summaries to `../sim/results/`. Run them from this folder. LTspice's component library is read from `%LOCALAPPDATA%\LTspice\lib\cmp\` (its standard install; `models.py`). In the archived logs, `<root>` stands for the project folder.

## Order to reproduce everything

The vendor models must first be downloaded into `../sim/models/` as its READMEs describe. Then, from this folder (the archived results were last regenerated in this order on 23 November 2026, without the servo; scripts that merge into their results file, or skip entries already present, as `comp_search.py` does, start from an empty file):

1. Models and the benchmark: `models.py` (or any script, which calls it), `sr560_frontend.py`, `sr560_chain.py all`, `sr560_bw_check.py`, `sr560_variants.py` (after `sr560_bw_check.py`, whose fits it uses), `sr560_nf_datasheet.py`.
2. Front ends: `collect_curves.py`, `protection.py`, `stability_corners.py`, `gain_options.py`, `gain_options.py derived`, `op_pitfall.py`, `lv_option.py`, `sink_options.py`, `sink_options.py chain`, `servo_check.py`, `sink_power.py`, `sink_power.py tab`, `osc_check.py H100 0 33 100 150 220`, `osc_check.py H10 220`, `osc_check.py L200 470`, `osc_check.py first`, `osc_check.py first H100 L200 --ties`, `comp_search.py H100`, `comp_search.py H10`, `comp_search.py L200`.
3. Chain: `chain.py ac`, `chain.py noise`, `noise_vs_source.py`, `nf_map.py`, `nf5113_manual.py`, `sr560_nf_sources.py`, `chain_extras.py`, `da_compare.py`, `da_compare.py hr`, `cmrr_mc.py 12` (all cases, the one-class cases with 6 trials and the $R_{UP}$ test with 4), `large_signal.py H100 thd step psrr`, `large_signal.py L1000 thd step overload psrr`, `large_signal.py floor` (after the THD runs, whose time grids it reuses), `overload_detail.py`, `overload_detail.py --h-ths4031`, `large_signal.py repro THS4031`, `large_signal.py repro L1000_step`.
4. Closed forms and model checks: `overload_detail.py numbers`, `fe_closed_forms.py`, `opamp_noise_check.py`, `model_defects.py`, `jfet_model_check.py`, `noise_theory.py`, `jfet_data.py`, `nf5307_plot_check.py`, `ti_plot_check.py`.
5. Derived numbers: `numbers_s4a.py`, `numbers_s4b_5.py`, `numbers_s6_7.py`, then `numbers_s1_3.py` (it imports `numbers_s6_7.py`).
6. Figures, netlists and the note: `make_figures.py`, `make_schematics.py`, `export_netlists.py`, `build_note.py`, `make_web_html.py`.
