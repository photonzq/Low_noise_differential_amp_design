# SPICE models: TI, Linear Integrated Systems, Toshiba, onsemi JFETs

All files accessed 2026-11-19 and stored as downloaded (archives kept next to a folder of the same name holding their extracted contents). Model files have not been edited. Paths are relative to `sim/models/`.

Noise model reminder (standard SPICE NJF): drain flicker-noise current PSD $= KF\cdot I_D^{AF}/f$; input-referred $e_{n,1/f}^2 = KF\cdot I_D/(g_m^2 f)$ for $AF=1$; channel thermal noise $8kT/(3g_m)$ referred to the gate. `Nlev`, `Gdsnoi` are LTspice-specific NJF noise options (Nlev = 3 selects the alternative channel-noise formulation scaled by Gdsnoi); other simulators may ignore them. RD/RS add thermal noise.

## Toshiba (and parts requested as Hitachi)
